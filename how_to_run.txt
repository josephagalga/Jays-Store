PROJECT SETUP GUIDE (WINDOWS)

This project requires two servers to be running at the same time: 
one for the Backend (Django) and one for the Frontend (React + Vite).

===========================================================================
PART 1: BACKEND SETUP (DJANGO)
===========================================================================

1. OPEN TERMINAL:
   - Open Command Prompt or PowerShell.
   - Navigate to the 'backend' folder:
     cd C:\Users\user\Desktop\store\Jays-Store\backend

2. CREATE & ACTIVATE VIRTUAL ENVIRONMENT:
   - Create the environment (if not already created):
     python -m venv venv
   - Activate the environment:
     venv\Scripts\activate

3. INSTALL REQUIREMENTS:
   - With the environment active (you should see (venv) in the prompt), run:
     pip install -r requirements.txt

4. CONFIGURE ENVIRONMENT:
   - Ensure the `.env` file exists in the `backend` directory with appropriate keys (see `.env.example`).

5. DATABASE MIGRATIONS & SEED DATA:
   - Apply migrations first:
     python manage.py makemigrations
     python manage.py migrate
   - Seed sample products:
     python manage.py seed_products
   - Create test users (admin, buyer, seller, driver):
     python manage.py create_test_users

6. START DJANGO SERVER:
   - Run:
     python manage.py runserver
   - KEEP THIS TERMINAL WINDOW OPEN. Default runs on http://127.0.0.1:8000

===========================================================================
PART 2: FRONTEND SETUP (REACT + VITE)
===========================================================================

1. INSTALL NODE.JS:
   - Make sure Node.js is installed (https://nodejs.org/).

2. OPEN SECOND TERMINAL:
   - Open a NEW, SECOND terminal window.
   - Navigate to the 'frontend' folder:
     cd C:\Users\user\Desktop\store\Jays-Store\frontend

3. INSTALL DEPENDENCIES:
   - Run:
     npm install

4. START FRONTEND DEV SERVER:
   - Run:
     npm run dev

5. VIEW SITE:
   - Open your browser to: http://localhost:5173
